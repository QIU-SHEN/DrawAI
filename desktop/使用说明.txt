DrawAI 免安装版 · Windows 10/11 64 位

1. 将 ZIP 完整解压到固定文件夹，双击 DrawAI.exe。
   不要直接在压缩包内运行，不要只拷贝 EXE；整个文件夹都需要保留。
   运行缓存写入程序旁的 data 文件夹，请放在有写入权限的位置。
2. 点右上角「保存」或 Ctrl+S，保存当前工作空间为 .drawai 图表。
   Ctrl+Shift+S 另存为。每个工作空间可独立保存成文件。
3. 首次使用：文件菜单 → 关联 .drawai 文件 → 关联。
   此操作仅登记当前用户的文件关联，无需安装或管理员权限。
   之后双击 .drawai 文件即由 DrawAI 打开；也可点「打开」或 Ctrl+O。
   如果 Windows 询问打开方式，请选择本文件夹中的 DrawAI.exe，并勾选始终使用。
4. 移动了程序文件夹：重新运行 DrawAI.exe，再关联一次文件后缀。
5. 文件不会在每次修改时自动覆盖，请使用 Ctrl+S 保存。关闭前会提示未保存修改。
   同一文件重复打开会聚焦已有窗口；其他文件在独立窗口打开。
   若文件已被外部修改，保存会停止，请另存为或重新打开原文件。
6. 原网站的 JSON 可从「导入」导入，再保存为 .drawai。
   右上角「导出文件」生成 .drawai 副本，不改变原文件的保存位置。
7. 发给别人：发送此完整 ZIP 和 .drawai 文件。对方也需要解压运行一次并关联后缀。
   .drawai 文件使用 DrawAI 程序打开；它是专用格式，不是加密文件。

当前为未签名的测试版，没有购买 Windows 代码签名证书。
本程序不需要联网或安装浏览器；图表保存在你选择的位置。

启动只创建一个空白图层，不附带示例图表。
顶部「主题」菜单可切换强调色，只替换原粉色区域；黑白灰画布保持不变。主题偏好保存在程序旁 data/theme.txt。
