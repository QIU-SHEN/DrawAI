# DrawAI 交互设计

DrawAI 是单人使用的空间图表编辑器。平面与三维共享同一份图形数据；图形、表格和连线不绑定特定业务功能。

## 默认状态

- 启动桌面程序时创建「工作空间 1」与一个空白「图层 1」，默认平面视图。
- 安装包不附带演示图表，生产代码不内置示例；回归夹具只放在 tests/fixtures。
- 已有图表通过原生打开或文件关联加载，不用空白文档覆盖旧文件。
- 「清空画布」只影响当前空间，需要确认且可撤销。

## 画布交互

- 平面仅显示当前图层；三维展示全部图层，支持连续 360° 旋转。
- 图层使用统一浅灰色与 85% 不透明度，按深度排序，上层阻挡对下层内容的鼠标操作。
- 选取模式支持框选与多选；拖动模式禁止框选，仍允许编辑单个图形。空白拖动控制相机。
- 从图形库拖入 12 种普通形状或表格。节点与表格可移动、缩放、连接；三维可跨层拖动。
- 双击/F2 原位编辑；单击不自动展开属性窗。Enter 保存，Shift+Enter 换行，Esc 取消；输入法组词时 Enter 不提前提交。
- 连线可从任意边缘点出发，四边中心点吸附；双击连线编辑文字。
- 多张表格彼此独立，标题、列名和内容自由编辑，支持增删行列。

## 工作空间和文件

工作空间独立保存图层、节点、表格、连线与撤销记录。图层可以新增、删除、重命名和上下排序。各空间分别绑定 .drawai 文件；保存更新绑定文件，另存为切换绑定，导出只创建副本。

浏览器版使用 localStorage；桌面版使用原生文件操作。历史 JSON 与 HTML 的兼容逻辑保留，但新版只导出 .drawai。

## 主题

默认经典粉 #EC7FA4。原生「主题」菜单位于「文件」旁，可选择粉、蓝、绿、紫、橙。只替换强调色、深浅强调色与选区；黑白灰画布、节点底色和正文保持不变。

主题是应用偏好，存于程序旁 data/theme.txt；在窗口间同步，重启恢复，不写入图表，不产生图表未保存状态。

详细文件结构见 [数据模型](03-data-model.md)，宿主说明见 [Electron](desktop.md) 与 [WebView2](webview2.md)。
