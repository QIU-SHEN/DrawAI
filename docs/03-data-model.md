# DrawAI 文档数据

当前图表版本：3。网页版使用 localStorage，无服务端数据库。每个浏览器独立保存，JSON 可导入导出。

桌面版新增 `.drawai` 文件容器 `{ format: 'drawai', version: 1, workspaceName, document, view }`，document 继续使用 v3 校验。单文件对应单工作空间，最大 12 MB；只保存结构化图表数据，不包含可执行代码。Electron 主进程验证内容并通过同目录临时文件写入、flush、rename 替换原文件；写入前后检查旧文本，发现外部修改或移动则拒绝覆盖。保存完成只将该快照标为已保存，写入期间的新修改仍为未保存。

桌面每个窗口有独立随机存储命名空间，打开文件始终以磁盘内容为准；文件路径绑定保留在主进程会话，渲染层无通用读写路径权限。各工作空间独立绑定文件，另存为更新该空间绑定。内容/名称修改标脏，纯视角改变不标脏但随下一次保存落盘。关闭时先提交原位编辑，再依次保存所有未保存空间（可取消）。网页和离线 HTML 的存储/原文件回写规则不变。

工作空间目录单独存于 `<base>.workspaces`，格式 `{ version: 1, activeId, items: [{ id, name, view? }] }`，最多 50 项，包含 `default`，名称 1–60 字，ID 唯一。在线 base 为原 `drawai.document.v1`；离线 base 为文件独立 storageKey。默认空间继续使用 base 键以兼容历史图表，其他空间各存于 `<base>.workspace.<id>`，文档仍为 v3。目录不含图表内容；无目录时直接承接旧图。目录异常保留 recovery 副本；非默认空间图表异常时不切换、不覆盖其数据。每个空间的 History 与文档在内存中分别维护，切换前提交并保存；浏览器存储不可用时仍可会话内切换和导出。

每次导出只嵌入当前空间的图表与名称，不包含工作空间目录或其他空间的数据。HTML 容器新增可选 workspaceName，旧文件仍可打开。离线原文件写入始终读取 default 对应的文档/视图与名称，即使写入期间切到另一空间，也不会将当前其他图表写回原文件。离线新增空间可各自导出单独文件。

HTML 导出容器格式为 `{ format: 1, storageKey, revision, document, view, assets }`：`document` 仍是经过校验的 v3 数据；`view` 保存平面/三维、角度、层间距、当前层和关联显示开关；`assets` 是构建时生成的页面、CSS 和独立作用域脚本；`revision` 为每次导出/回写生成的 UUID（兼容旧文件无此字段）。容器通过转义 `<` 的 application/json 脚本元素嵌入，用户文本不插入可执行脚本或 HTML。内置编辑器不依赖网络、ES 模块加载器或 eval。

站点存储键不变；每次 HTML 导出生成独立 `drawai.file.<UUID>` 键。离线初始图表先从文件读取，仅当 `.file-revision` 存档元数据与内置 revision 一致时恢复其专属浏览器草稿（无 revision 的旧格式按原规则恢复）；存储被禁用时仍可打开、回写文件和再次导出。离线再次导出复制原始静态资源与最新图表，不嵌套旧 HTML。

原文件自动保存仅在离线编辑器启用，通过用户手势调用 `showOpenFilePicker` 并取得 readwrite 权限。文件句柄仅保留在当前页面内存；每次重新打开须重新关联。以 storageKey + revision 校验文件归属与版本，读取文件文本与上次成功写入的文本比较，发现外部修改则停止回写。每次写入重新构造完整 HTML，维持原 storageKey，生成新 revision；createWritable / write / close 全部成功后更新版本与状态。失败尝试 abort，保留待写状态供手动重试；同时只运行一个写入循环，写入期间的新改动进入下一轮。关闭页面时，若仍有未写入数据则触发浏览器离开提醒。视图随业务内容提交或立即保存时一起写入。

## 对象

节点 kind 新增通用值 `shape`，图形库所有新节点使用此值，不承载业务角色。旧 `agent/input/decision/result` 仍可读取并保留，属性界面不再提供业务类型选择。shape 新增 `triangle/trapezoid/pentagon/hexagon/octagon/chevron`，与原圆角矩形、矩形、菱形、椭圆、平行四边形和文本共 12 种。多边形轮廓用于绘制和自由连接点定位，缩放后端点仍贴合边缘。当前格式仍为 v3；带新枚举值的文件需使用新版编辑器打开。选取/拖动工具、框选矩形和多选 ID 集合只属会话 UI 状态，不写入图表；整组移动只更新各对象坐标，整组删除清理关联边，均只记一次 History。

- `layers`: `{ id, name }[]`，顺序决定高度，1–20 层。
- `nodes`: `{ id, kind, shape, layerId, title, description, x, y, width?, height? }[]`，最多 200 个，位置为中心。
- `tables`: `{ id, layerId, x, y, width, height, title, columns, cells }[]`，最多 50 张，位置为左上角。`columns` 是列名字符串数组；`cells` 是与列数一致的二维字符串数组。没有固定业务字段。
- `edges`: `{ id, source, target, label, sourcePort?, targetPort?, style? }[]`。端点统一引用节点或表格 ID；`style` 可为 `solid` 或 `dashed`，省略为实线。新增箭头默认实线；迁移的共享关联保留虚线。每种样式同向端点不得重复，迁移时可同时保留原流程边和原共享虚线。

`sourcePort` / `targetPort` 可为旧版方向字符串 `n/e/s/w`，或自由连接点 `{ x, y }`。自由点坐标相对于对象中心，以半宽/半高归一化，两个值均有限且范围为 [-1, 1]；渲染时重新贴合真实轮廓，使尺寸变化后圆角等曲面上的点仍在边缘。旧方向字符串保持中点吸附语义，缺省端点沿用自动布局。本次是 v3 兼容字段扩展，无需重新迁移历史文档；导入导出保留自由点，校验拒绝越界、缺失值及非有限坐标。

表格默认 720×280、3 列3行，标题「表格」，列名与内容为空。宽高允许 240–4000 和 100–4000。每张表最多 500 行、20 列，至少一列、可零行；全图数据单元格最多 10000 个。标题/列名限 100 字符，单元格限 1000 字符。节点、表格 ID 共用命名空间，所有坐标为有限值且绝对值不超过 10000。

连线文字最长 60 字符。新建最多 1000 条边；导入校验允许 1200 条以容纳旧版 1000 条流程边加最多 200 个 Agent 共享关联。JSON 导入限制 12 MB。所有输入校验引用、类型、长度、尺寸及唯一性；仅保留已知字段，渲染前转义。

## 迁移

存储键继续使用 `drawai.document.v1`。读取 v1/v2 时先用旧校验器验证，再构造新的 v3 对象，不修改旧输入。

1. v1 先恢复默认图层及图形类型，沿用已有迁移规则。
2. v2 `table` 转为 `tables` 中的一个独立对象，保留位置和尺寸。ID 默认 `table-shared`；冲突时增加后缀。
3. `rows` 转为四列普通文本：检查项、结果、关联 Agent、备注。关联 ID 展开为旧节点名称，保留全部行和备注。原「共享检查表」只作为可编辑的初始标题。
4. `@shared-table` 流程端点替换为新表 ID。每个已有共享关联聚合成一条虚线，保留节点上的 `relationLabel`，默认「读取 / 回写」；生成不冲突的独立边 ID。
5. 删除旧 `table`、`rows` 和节点 `relationLabel` 字段；表格文字和边不再相互生成。原状态词仍在单元格中，但没有选项限制。

首次浏览器迁移前将原 JSON 保存为 `drawai.document.v1.before-tables`，不覆盖既有备份；v1 原有 `.before-layers` 备份继续保留。正常编辑保存 v3，JSON 导入仍可撤销。无效文件不覆盖当前画布；无效浏览器存档另存恢复副本。

## 删除与历史

删除节点或表格只删除该对象及引用它的边。删除图层清理本层所有对象和相应边，其他表格单元格不变。表格编辑使用独立草稿，保存时一次历史操作，Esc 丢弃；图形移动、缩放、增删表格和连线均可撤销/重做，最多 80 个历史快照。

## 回滚

发布版本保留在 Sites，必要时可切回上一版本。旧版程序不能编辑 v3 多表格文件，因此回滚前先导出最新 v3 JSON 保留新增内容，并从 `.before-tables` 备份恢复原 v1/v2 数据；不得直接把 v3 当成旧版数据覆盖。优先向前修复，以保留发布后新建的多表格内容。

## 诊断与 AI 表格副本（0.7.3）

文档校验保留原有限制，错误包含字段路径和原因。AI 返回结果单独做有限规范化：只移除 nodes 中 kind=table 且与 tables 同 ID、全部其他字段完全相同的副本。冲突仍拒绝，连线继续指向原表 ID。文件导入不进行此规范化，避免猜测用户文件含义。

0.7.4：AI JSON/图表校验失败时，将具体错误和上一条回复反馈给模型，最多自动重试 2 次。尺寸限制不变，不由客户端改写越界值；仅完整有效的结果会一次性应用。原图、原始需求与图片在重试期间保留，文件导入规则不变。
