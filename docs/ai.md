# AI 做图

0.7.1 起 AI 对话面板仅在 WebView2 桌面版提供，在线站点为纯手工绘图。用户自行提供 API 地址、API Key 和模型；程序不内置模型、密钥或付费额度，普通绘图仍可离线使用。

## 使用

1. 点击顶部「AI 做图」，展开「API 设置」。
2. 填写兼容 OpenAI Chat Completions 的基础地址（如 `https://api.example.com/v1`）或完整 `/chat/completions` 地址、API Key 和服务商的模型名称。本地无鉴权接口可以留空 Key。
3. 保存设置，可先「测试连接」（会向所填模型发送一条小请求）。
4. 输入要画的内容，例如「画一个请假审批流程，超过三天增加主管审批」。生成结果是普通图形、表格和连线，可以继续手工编辑。
5. 继续对话，例如「把主管审批移到第二层，并增加驳回分支」。每轮成功应用作为一次撤销操作。

「＋ 图片」支持选择文件，也可在输入区域粘贴截图或拖入图片。支持 PNG / JPEG / WebP，每次最多 3 张，单张 4 MiB，总计 8 MiB，单张最多 2400 万像素。只发图片时默认要求还原成可编辑图表。图片仅随当轮发送，不作为画布图片节点保存；下一轮若仍需识图，可再次附图。**模型与接口必须支持图片输入**，普通文字模型无法识图。

## 接口与数据

- 协议：`POST /chat/completions`，JSON 包含 `model`、`messages`、`stream:false`；可选 `Authorization: Bearer …`。图片使用 `image_url` 的 Base64 data URL。完整地址保留查询参数；不支持 URL 中的用户名/密码、锚点或 HTTP 重定向。
- 系统提示给出 DrawAI v3 文档格式；模型应返回 `{"message":"说明","document":完整文档或null}`。`null` 表示仅交流，不改图。回复会通过现有模型校验器，不执行代码或 HTML。
- 每次发送当前工作空间的完整图表、最多 10 条最近对话和本次图片，**直接发送到用户配置的服务商**；不会经过 DrawAI 的服务器。用户需自行判断服务商的数据政策与费用。
- 地址与模型保存在本机浏览器存储。API Key 仅保留在当前窗口内存，重启/刷新后重新填写。对话输入和附图只在当前窗口保留；模型回复会进入下述本机诊断日志。这些内容不写入 `.drawai` 文件、发布包或源码。
- WebView2 由本机宿主直接发起 HTTP 请求，避免浏览器跨域限制。在线站点不提供 AI，历史 Electron 实现不再作为当前交付。无公共代理。
- 每次尝试超时 120 秒，可手动停止整个生成过程；请求上限 16 MiB、回复上限 2 MiB。鉴权失败、截断或无效图表会显示错误，画布保持不变。
- 等待回复期间若画布或工作空间变化，结果不会覆盖当前图；可点击「在新工作空间查看结果」。

当前未实现流式输出、模型列表发现、原生 Responses/Anthropic/Gemini 协议或本地模型安装。服务商若提供 Chat Completions 兼容地址，可按上述方式接入。图表复杂度与还原质量取决于模型；建议先生成主要结构，再逐步补充分支。

## 返回数据处理（0.7.4）

提示明确要求表格只出现在 `tables`，连线直接引用表格 ID。如果模型将同一表格同时写进 `nodes`（`kind: "table"`）和 `tables`，且除 kind 外全部字段完全一致，AI 处理层会合并为一张表，并提示合并数量；所有内容、坐标、尺寸和连线 ID 保留。不自动合并字段有差异的表格，也不修复悬空引用或覆盖普通图形的重复 ID。JSON 解析或图表校验失败时，客户端将具体错误路径和原因连同模型上一条回复发回模型，要求返回修正后的完整图表，最多自动重试 2 次（共最多 3 次调用）。例如表格宽 200 会将 `tables[0].width：必须为 240–4000 的数字` 反馈给模型，不在客户端改写尺寸。重试保留原始需求、当前图表及本次图片；只在完整校验通过后一次性应用，支持撤销。修正回复不能用 `document:null` 跳过修复；普通交流仍允许 null。网络、鉴权、限流、接口错误、拒绝或截断不触发自动修正。每次尝试独立记录日志，日志中带共同任务编号和尝试次数。界面显示重试进度，停止后不再继续。普通文件导入仍严格校验。

校验错误现在包含具体路径，例如 `nodes[4].kind`、`tables[0].id`、`edges[2].target`，界面和日志均保留原因。

## 请求日志（0.7.2）

每次 AI 请求自动记录到程序旁的 `data/logs/ai/ai-*.json`，保留最近 20 次请求。包括 UTC 时间、请求编号、应用版本、接口路径（不含查询参数）、模型、消息/图片数量、HTTP 状态与 Content-Type、耗时、原始响应正文及客户端解析/校验结果。超大回复记录已收到的前缀并标注截断。网络失败、主动停止和超时也记录；请求输入文本、当前图表和图片内容不会作为请求日志保存。

点击 AI 对话栏底部「查看日志」，可选择请求、查看原始 HTTP 回复和解出的模型正文、复制日志或打开日志文件夹。日志独立于对话，清空对话或重启程序后仍在。API Key、接口地址中敏感查询值及图片 data URL 会脱敏；日志仍可能包含模型返回的图表文字，分享前请检查。日志不会自动上传，也不进入分发包。

日志写入失败会在界面提示，但不会阻止正常绘图。新版本无法恢复旧版本未记录的回复；遇到旧截图中的问题，需要在新版本重新请求一次。

## 实现与验证

`src/ai.js` 负责提示、接口和结果校验，`src/ai-panel.js` 管理对话、图片和请求生命周期。WebView2 消息桥仅向受信任的应用主页面开放；本机 HTTP 不跟随重定向，窗口关闭时取消请求。

测试使用本机模拟兼容接口，覆盖文字/图片载荷、连续修改、撤销、取消、错误、并发编辑保护、密钥存储隔离，以及真实 WebView2 桌面宿主。没有使用真实服务商密钥测试模型生成质量。

协议参考：[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。
